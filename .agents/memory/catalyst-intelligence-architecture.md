## Core design

Pre-earnings / catalyst analysis feature. Deterministic in Part 1 (no AI). AI deep analysis is Part 2.

**Repository keys:**
- `catalyst-intelligence:<TICKER>` — CatalystState (screening + facts + analysis)
- `company-driver-profile:<TICKER>` — CompanyDriverProfile (generated by CM in Part 2)

**Module files (all under `src/lib/`):**
- `catalyst-types.ts` — ALL shared types, enums, interfaces (do not duplicate elsewhere)
- `catalyst-price-asymmetry.ts` — deterministic PriceAsymmetryFacts from PriceContext
- `catalyst-screening.ts` — pure `screenCatalystCandidate()` function + fingerprint + evidence confidence
- `catalyst-facts-builder.ts` — assembles CatalystFacts from repository (no AI, no Saxo)
- `catalyst-repository.ts` — thin wrappers over analysisRepository

**Route:** `src/routes/catalyst-intelligence.ts`
- POST /api/catalyst-intelligence/screen (all or specific tickers)
- POST /api/catalyst-intelligence/screen/:ticker
- GET  /api/catalyst-intelligence/status
- GET  /api/catalyst-intelligence/debug/:ticker
- GET  /api/catalyst-intelligence/facts/:ticker

## Key data availability findings

| Data | Status |
|------|--------|
| PriceContext (returns 1D/5D/10D/30D/90D) | Available |
| Upcoming earnings date | CM.earningsAndGuidance.nextKnownEventDate (AI-sourced) |
| Historical earnings / EPS | NOT available from Saxo — interfaces only, isUnavailable:true |
| Analyst consensus | NOT available from Saxo — interfaces only, isUnavailable:true |
| Company Driver Profile | NOT yet generated — Part 2 adds CM-driven generation |

## CM schema quirks (IMPORTANT)

- `cmResult.investmentView` is an OBJECT `{ rating, outlook, reason }`, NOT a plain string.
  Use `resolveInvestmentView()` in catalyst-facts-builder.ts to extract the `rating` field.
- `cmResult.investmentCaseStrength` is a NUMBER (0–100), NOT a string like "Medium".
  Convert: ≥70→High, ≥40→Medium, <40→Low.

## Orchestrator integration

- Module ID: `"catalyst-intelligence"` added to ModuleId union
- `supportsAutomaticRun: false` — Part 1 is manual only
- Part 2 will set `supportsAutomaticRun: true` and add AI deep analysis

## Screening funnel (deterministic)

1. Event eligibility: daysUntilEvent in [minDaysUntilEvent=1, maxDaysUntilEvent=30]
2. Price asymmetry: from PriceContext (runupPattern + trend context)
3. Company quality guard: Sell/Reduce/Negative view → NotInteresting
4. Evidence confidence: dedup by source+sourceType; echo chamber (same source, multiple signals) → Low
5. Level: ≤14D→DeepAnalysis, ≤21D→SignalAssessment, else→BasicMonitor

## Fingerprint

`computeCatalystFingerprint(facts)` — SHA-256 of structured key including:
- eventDate, daysBucket (7-day bins)
- priceState, trend labels, runupPattern, priceAsymmetry
- momentum30D/90D binned to nearest 5%  ← NOTE: avoid half-integer boundaries (JS Math.round(-5.5) = -5, not -6)
- investmentView, investmentCaseStrength, earningsGuidanceTrend
- signalCount + sorted signal directions

**Why:** Changed fingerprint = AI re-analysis warranted; same = skip costly AI call.
