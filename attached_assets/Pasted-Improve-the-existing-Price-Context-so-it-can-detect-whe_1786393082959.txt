Improve the existing Price Context so it can detect when a strongly falling stock is beginning to FLATTEN OUT in the most recent trading days.

IMPORTANT:
Do NOT redesign or replace the existing Price Context implementation.

Keep all existing:
- 1D / 5D / 10D / 30D / 90D returns
- short/medium/long trend
- normalized slopes
- volatility
- range position
- momentumChange
- PriceState
- OpenAI integrations

The current implementation correctly describes the broader trend, but it does not capture very recent stabilization well enough.

For example SERV currently shows approximately:

5D: -10.27%
1M: -15.64%
3M: -39.93%
Short/medium/long trend: StrongDowntrend
Momentum: AcceleratingNegative

This can all be true even if most of the 5D decline happened early in the 5-day window and the last 2-3 trading days have started moving sideways.

We therefore need a separate VERY SHORT-TERM BEHAVIOR calculation.


==================================================
1. ADD VERY SHORT-TERM METRICS
==================================================

Extend PriceContext with something conceptually like:

recentBehavior: {
    twoDayReturnPct,
    threeDayReturnPct,

    threeDaySlope,
    fiveDaySlope,

    daysSinceRecentLow,
    newLowLast3Days,
    newLowLast5Days,

    declineDecelerating,

    state
}

Possible recentBehavior.state values:

FallingFast
Falling
DeclineSlowing
Stabilizing
Recovering
Rising

These describe ONLY the most recent price behavior.

They must NOT replace the existing broader PriceState.


==================================================
2. DETECT DECELERATION
==================================================

The important question is:

"Is the negative price movement losing speed?"

Compare slopes across windows.

For example:

10D slope = strongly negative
5D slope  = negative
3D slope  = near zero

should indicate that the decline is DECELERATING.

Do not simply compare percentage returns because a large move early in a window can dominate the total return.

Use the normalized regression slopes already used by Price Context where possible.

Conceptually:

strong negative longer slope
→ less negative shorter slope
→ near-zero latest slope

= declineDecelerating: true


==================================================
3. DETECT RECENT STABILIZATION
==================================================

Create conservative deterministic rules for:

recentBehavior.state = Stabilizing

It should require a combination of evidence, for example:

- broader trend is Downtrend/StrongDowntrend
- recent 2D/3D movement is small relative to the previous decline
- 3D normalized slope is approximately flat
- negative slope has materially weakened versus 5D/10D
- stock is not continuing to make significant new lows
- optionally volatility is declining

Do NOT classify stabilization just because one day was positive.

Centralize thresholds so they can be tuned later.


==================================================
4. RECENT LOW BEHAVIOR
==================================================

Calculate whether the stock continues making new lows.

Add:

daysSinceRecentLow
newLowLast3Days
newLowLast5Days

Use a sensible recent comparison window such as the existing 30D range.

The purpose is to distinguish:

A)
price continues making new lows
→ decline probably still active

from:

B)
large decline occurred
→ price has remained above the low for several sessions
→ short-term slope approaches zero
→ possible stabilization

Do not interpret this as a confirmed bottom.


==================================================
5. KEEP LONG-TERM AND RECENT STATE SEPARATE
==================================================

This is very important.

Do NOT change:

PriceState = StrongDowntrend

to:

PriceState = Stabilizing

just because the last few days flatten.

Both should be allowed simultaneously:

PRICE STATE:
StrongDowntrend

RECENT BEHAVIOR:
Stabilizing

This gives us much better information:

"The stock remains in a strong broader downtrend, but very recent selling pressure appears to be stabilizing."

That is exactly the distinction we want.

Add the compact recentBehavior result to the existing Price Context sent to:

  }
}

Example values only — do not hardcode.


==================================================
7. UPDATE OPENAI PROMPTS
==================================================

Explicitly explain the distinction:

PriceState describes the broader price trend.

recentBehavior describes what is happening in the latest few trading sessions.

Therefore this is valid:

PriceState = StrongDowntrend
recentBehavior = Stabilizing

Interpretation:

"The stock remains in a strong downtrend, but the most recent price behavior indicates that negative momentum may be losing strength."

IMPORTANT:

Stabilizing does NOT mean:
- bottom confirmed
- reversal confirmed
- stock is cheap
- stock will rise
- BUY

Recovering also does not by itself mean BUY.

Trade Decision must still combine this with:
- fundamentals
- valuation
- news
- catalysts/events
- portfolio fit
- risk
- position sizing
