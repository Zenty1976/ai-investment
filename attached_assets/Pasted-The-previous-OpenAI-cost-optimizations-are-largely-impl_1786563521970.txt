2. ADD RECENT-RUN GUARD FOR EXTERNAL OBSERVATION MODULES
========================================================

Dependency fingerprints work well for synthesis/analysis modules.

However, observation modules such as Market Monitor and News Monitor must inspect the outside world, so dependency fingerprints alone cannot determine whether the world changed.

Still, it is wasteful to repeat the same expensive web-search observation a few minutes after it just ran.

Add a separate RECENT-RUN GUARD for externally observing modules.

This is NOT the same as dependency fingerprinting.

Concept:

If a module completed successfully very recently and this is a normal Run All / automatic invocation:

SKIP the OpenAI/web-search call.

Reuse its latest result.

Suggested initial minimum refresh ages:

Market Monitor:
15 minutes

News Monitor:
15 minutes

Event Monitor:
60 minutes

Sector Monitor:
180 minutes

Opportunity Finder:
180 minutes

Investor Watch:
use its existing discovery/schedule behavior; do not make it more aggressive.

Company Monitor:
keep the existing fingerprint/discovery behavior.

These values must be centralized/configurable.

Do not hardcode them throughout the orchestrator.
