--------------------------------------------------
Purpose
--------------------------------------------------

The purpose of this module is to identify, explain and prioritize the risks affecting the current portfolio over the next 1-3 months.

This module must focus on risk.

It must not recommend trades.

It must explain:

- what could happen
- why it matters
- how likely it is
- how severe it could become

--------------------------------------------------
Data
--------------------------------------------------

Read the latest stored data from:

- Portfolio Manager
- Portfolio Analyzer
- Opportunity Finder
- Market Monitor
- Event Monitor
- News Monitor
- Sector Monitor

Use Company Monitor analyses for held companies whenever available.

Only use the Analysis Repository.

Never call Saxo.

Never communicate directly with other modules.

--------------------------------------------------
OpenAI
--------------------------------------------------

Use the existing OpenAI Responses API with Web Search enabled.

Use the stored analyses as the primary analytical context.

Use web search only to verify recent developments or identify important new information.

--------------------------------------------------
Prompt
--------------------------------------------------

Tell OpenAI:

You are an experienced institutional portfolio risk manager.

Analyse the current portfolio over the next 1-3 months.

Identify and prioritize the most important risks.

Evaluate:

- concentration risk
- company-specific risk
- sector risk
- macroeconomic risk
- geopolitical risk
- event risk
- liquidity risk
- currency risk
- opportunity cost
- portfolio diversification
- correlation between holdings

For every important risk explain:

- why it exists
- probability
- potential impact
- what should be monitored

Do not recommend buying or selling.

Use language such as:

Monitor
Review
Prepare for
Watch

Clearly distinguish:

- facts
- expectations
- analytical judgement

Avoid generic investment language.

Return JSON only.
